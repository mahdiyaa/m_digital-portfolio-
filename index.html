Estate Management Application 2026

Overview: A full stack estate management platform selected to be developed for a real external client, built by a 5-person team. The system digitises how an estate logs, tracks, and resolves property maintenance.

My role: I owned the system's flagship AI feature — a computer vision pipeline built on RF-DETR v2 that automatically detects property defects from uploaded images and generates the corresponding maintenance tickets, removing the manual inspection write-up step entirely.

Engineering highlights: I designed confidence-based triage so uncertain detections are routed for human review instead of silently creating bad tickets, and implemented IoU-based deduplication so the same defect photographed from multiple angles never spawns duplicate work orders.

Second AI feature: I also built an OCR feature that auto-digitises paper forms, converting handwritten and printed site records into structured data the system can search and report on.

Beyond my feature: I contributed to team-wide architecture and infrastructure decisions, helping shape how the services fit together and how the AI components were deployed alongside the rest of the application.

Why it matters: Defect reporting is slow, inconsistent, and easy to skip. Automating detection and ticketing makes maintenance faster to raise and far harder to lose track of.

DeadlineIQ — NYPxAWS Hackathon 2026 (2nd Place)

Overview: Built for the NYPxAWS Hackathon, DeadlineIQ is a full stack assignment deadline tracker that answers the question students actually have: not "what is due?" but "what should I work on right now?" The project placed 2nd overall.

What it does: Task entry from natural language or uploaded PDFs, milestone breakdowns, crash-week detection, a study planner, and automated reminders — so overloaded weeks are visible long before they arrive.

The core idea: I engineered a deterministic five-factor priority algorithm — urgency, stakes, effort, progress, and clashes — so every ranking is explainable rather than a black box. Results are surfaced through a dashboard, a workload heatmap, and a Focus Mode that shows one task at a time.

Deliberate use of AI: AI (via OpenRouter) is used only where it genuinely helps — parsing messy input and narrating priorities in plain English. Every AI path has a deterministic fallback, so the app stays fully reliable offline and never depends on a model to decide what matters.

Tech stack: React on the frontend; AWS Lambda, DynamoDB, S3, EventBridge, and SNS on the backend for a fully serverless, event-driven architecture.

Outcome: A 2nd place finish at the NYPxAWS Hackathon, with transparent prioritisation as its differentiator.
